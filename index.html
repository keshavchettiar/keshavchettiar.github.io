APSEC

A club web app I built to be hard to break into.

Node.jsExpressMongoDBJWTbcrypt
+ How it works
  • Three roles (Member, President, Treasurer) that each see only what they should, following OWASP guidelines.
  • Passwords hashed and salted with bcrypt, with strength rules and JWT login sessions.
  • Accounts lock after 5 failed logins, and login requests are rate limited to stop brute-force attacks.
  • A password reset link gets emailed through Nodemailer.
